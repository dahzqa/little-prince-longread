# Моя фотография с Маленьким принцем — исправленная версия

Готовый desktop-проект лонгрида. Базовая геометрия макета: 1046×587. Каждый экран масштабируется целиком под viewport.

## Запуск

```bash
npm run dev
```

или

```bash
yarn dev
```

Откройте `http://localhost:5173`.

Все шрифты, изображения, видео, GSAP и ScrollTrigger находятся локально внутри проекта.


## Важно

Полароиды из Figma не пересобираются CSS-рамками: используются исходные PNG-экспорты из макета (`assets/img/figma`).
